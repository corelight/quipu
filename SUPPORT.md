# Support

Quipu is an open-source project provided without a support SLA.

- Read the bundled guide or its source in [documentation/content](documentation/content).
- Ask usage questions, report bugs, or propose features in
  [GitHub Issues](https://github.com/corelight/quipu/issues).
- Include the Quipu version, Linux distribution, reproduction steps, and
  sanitized logs when reporting a problem.
- Report suspected vulnerabilities privately as described in
  [SECURITY.md](SECURITY.md).

Do not attach credentials, private rules, customer data, or live malware to an
issue.
